So the budget no longer fills the context; it only sets how many tools there are to search.

## What was run

`bench/recipes/scale-160-toolsearch.yaml` extends `scale-160.yaml` and sets only `harness_options.tool_search: on`. The report on this page was made by the last command.

```sh
python -m mockmcp eval recipe bench/recipes/scale-160-toolsearch.yaml --out runs/ts-on
python -m mockmcp eval run    runs/ts-on --model haiku
python -m mockmcp eval grade  runs/ts-on --judge claude-code   # Sonnet judge, the default
python -m mockmcp eval report runs/ts-on --html
```

Model: <code>{r.model}</code>. Judge: <code>{r.judge}</code>.

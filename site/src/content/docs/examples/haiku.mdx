## What was run

The run used `bench/recipes/scale-160.yaml` and the standard pipeline (`docs/BENCHMARKING.md`). The report on this page was made by the last command.

```sh
python -m mockmcp eval recipe bench/recipes/scale-160.yaml --out runs/ts-off
python -m mockmcp eval run    runs/ts-off --model haiku
python -m mockmcp eval grade  runs/ts-off --judge claude-code   # Sonnet judge, the default
python -m mockmcp eval report runs/ts-off --html
```

Model: <code>{r.model}</code>. Judge: <code>{r.judge}</code>.
